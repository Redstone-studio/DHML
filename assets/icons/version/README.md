# 版本类型图标

版本列表左边那个方块用的图。**没放图的话会自动退回原来的文字徽章**
（原 / FA / 包），所以可以慢慢补，不会因为缺一张图就出空白。

## 放什么格式

**PNG，64×64 或 128×128，带透明通道。**

- 不用 SVG：这些是像素画质感（草方块、铁砧），矢量化反而费劲，
  而且以后你自己换图时直接拿画图/像素编辑器导一张 PNG 就行
- 不用 ICO：ICO 是给 **exe / 任务栏**用的（一个文件里塞 16/32/48/256 多档），
  列表里显示的是可以随时缩放的小图，PNG 更合适

## 文件放这儿，名字要对上

| 文件名 | 什么时候用 | 你打算用的图 |
|---|---|---|
| `vanilla.png` | 正式版、快照（`release` / `snapshot`） | 草方块 |
| `old.png` | 远古版本（`old_alpha` / `old_beta`） | 圆石 |
| `forge.png` | Forge | 铁砧 |
| `fabric.png` | Fabric | — |
| `neoforge.png` | NeoForge | — |
| `quilt.png` | Quilt（可选） | — |
| `optifine.png` | OptiFine（可选） | — |

判定顺序是**先看加载器、再看版本类型** —— 加载器版本本身也是 `release`，
但你显然想看到铁砧而不是草方块。名字是**小写**，代码里做了大小写无关的包含匹配。

加新图标：把 png 丢进来，然后在 `ui/icons.py` 的 `_LOADER_ICONS` /
`_TYPE_ICONS` 里加一行。只加文件不加映射是**不会生效**的。

## 程序图标（另一回事）

启动器的**窗口图标 / 任务栏 / exe 图标**要用 **ICO**（多尺寸那个），
放 `assets/icons/app.ico`。那是另一条线，还没接。
